# Aura UI

Create a premium luxury clinical UI system.

STRICT RULES:
- Do NOT change colors
- Do NOT add extra sections
- Do NOT improvise layout

COLORS:
Background: #0F1115
Surface: #171A20
Primary: #C8A96A
Text: #FFFFFF / #BFC3C9

TYPOGRAPHY:
- Headings: serif (Playfair style)
- Body: Inter

SPACING:
- 8px grid
- Large whitespace

BUTTON:
- Gold background, black text
- Rounded 8px

MOBILE:
- Must be fully responsive

ACCEPTANCE CHECK:
- UI looks minimal, premium, not crowded
- Buttons clearly visible on mobile
